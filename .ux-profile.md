# UX profile (assumed defaults; edit freely)
- Aesthetic: Apple Native + Liquid Glass (custom). Warm amber accent on deep ink; pearl light theme.
- Ban list: rainbow CTAs, cartoon empties, decorative pill metadata, neon glow stacks, looping decoration.

- Icons: lucide-react (existing).
